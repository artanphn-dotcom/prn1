To configure your `git` identity, open your terminal and run these two commands:

1.  **Set your user name:**
    ```bash
    git config --global user.name "Your Name"
    ```
    (Replace "Your Name" with your actual name, e.g., "John Doe")

2.  **Set your user email:**
    ```bash
    git config --global user.email "you@example.com"
    ```
    (Replace "you@example.com" with your actual email address, e.g., "john.doe@example.com")

After running these commands, you can then try `npm run deploy` again.
